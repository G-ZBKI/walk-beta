# walk-beta

A browser-based courtyard walking demo with keyboard controls, hold-to-walk mouse movement, and a portal to a future second scene.

## Controls

- W or Up Arrow: move forward
- A/D or Left/Right Arrow: turn
- Hold left mouse: walk toward the pointer
- Space: jump
- Shift: run
- E: interact

## Publish on GitHub Pages

Upload this folder to a GitHub repository, then open:

Settings -> Pages -> Build and deployment -> Deploy from a branch -> main -> /root -> Save

After GitHub finishes deploying, the game will be available at:

https://YOUR-GITHUB-NAME.github.io/REPOSITORY-NAME/
