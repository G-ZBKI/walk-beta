# walk-beta

A browser-based courtyard walking demo with keyboard controls, hold-to-walk mouse movement, animated grass, fluffy clouds, small rocks, robot sweepers guarding a cyber orb, an FPS counter, and a portal to a future second scene.

## Controls

- W or Up Arrow: move forward
- A/D or Left/Right Arrow: turn
- Hold left mouse: walk toward the pointer
- Space: jump
- Shift: run
- E: interact
- Find the cyber orb: sweepers free-roam until one spots you, then all rush to block you
- Type cheat: unlock flying
- Double-tap Space after cheat: toggle flying
- While flying: hold Space to go up, hold Shift to go down

## Publish on GitHub Pages

Upload this folder to a GitHub repository, then open:

Settings -> Pages -> Build and deployment -> Deploy from a branch -> main -> /root -> Save

After GitHub finishes deploying, the game will be available at:

https://YOUR-GITHUB-NAME.github.io/REPOSITORY-NAME/
